# 🌱 CropCareAI

### AI-Powered Smart Agriculture Platform

An intelligent agriculture platform that leverages Artificial Intelligence and Machine Learning to assist farmers with crop recommendation, fertilizer recommendation, plant disease detection, plantation analysis, weather insights, and multilingual support.

## 📖 Overview

CropCareAI is a full-stack smart agriculture platform designed to empower farmers through AI-driven decision-making. The system combines Machine Learning, Computer Vision, weather intelligence, and multilingual accessibility to improve agricultural productivity and sustainability.

---

## ✨ Key Features

- 🌾 AI-Based Crop Recommendation
- 🌱 Smart Fertilizer Recommendation
- 🍃 Plant Disease Detection using Deep Learning
- 🌳 Plantation Detection from Images
- ☁ Real-Time Weather Information
- 🌍 Multilingual Translation Support
- 📱 Fully Responsive User Interface
- 🔐 Secure Authentication
- 📊 Farmer-Friendly Dashboard

# ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/Chaitanya-1020/CropCareAI.git
```

```bash
cd CropCareAI
```

---

### Install Backend Dependencies

```bash
npm install
```

---

### Install Frontend Dependencies

```bash
cd frontend
npm install
```

---

### Install Python Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶ Running the Application

Open **three separate terminals**.

### Backend Server

```bash
cd CropCareAI
npm start
```

---

### Frontend

```bash
cd CropCareAI/frontend
npm run dev
```

---

### AI Service

```bash
cd CropCareAI
python fly.py
```
