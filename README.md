# 🌱 CropCareAI

An AI-powered Smart Agriculture platform for crop recommendation, fertilizer recommendation, plant disease detection, plantation detection, weather updates, and multilingual support.

---

## 🚀 Run Locally

### Terminal 1 (Backend)

```bash
cd CropCareAI
npm start
```

### Terminal 2 (Frontend)

```bash
cd CropCareAI/frontend
npm run dev
```

### Terminal 3 (Python AI Server)

```bash
cd CropCareAI
python fly.py
```
